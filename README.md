# Folia 随身歌词播放器（PWA）

一个自托管的本地音乐 + LRC 歌词同步播放器，可添加到 iPhone 主屏幕、全屏离线运行。

## 功能
- 本地添加音乐：点右上角「+」从「文件」/「相册」选择音频（MP3/M4A/FLAC/WAV/OGG/AAC/Opus 等），也支持桌面拖拽。
- 全屏沉浸歌词：进入播放页即全屏，封面吸色背景 + 三段式歌词，当前行琥珀高亮，点歌词可跳转。
- 歌词同步：在曲库点歌曲右侧「铅笔」，为它添加 `.lrc` 歌词文件（或粘贴文本）即可逐行同步。
- 封面：可单独为每首歌添加封面图片，用作背景氛围色与列表缩略图。
- 播放控制：上一首 / 下一首 / 进度拖拽 / 音量 / 四种播放模式（顺序·列表循环·单曲·随机）。
- 离线可用：Service Worker 缓存应用外壳，曲库数据存在本地 IndexedDB，音频不上传。

## 怎么装到 iPhone（按需选一种）

PWA 必须通过 http/https 访问，**不能直接双击打开**（manifest 只有通过服务器访问才会加载）。

### 方式一：本机局域网服务器（最快，无需账号）
1. 把整个 `folia-ios-pwa` 文件夹放到任意位置。
2. 在本目录启动一个静态服务器，例如 Python：
   `python -m http.server 8000`
   （需在本机防火墙放行 8000 端口，并让手机和电脑连同一个 Wi-Fi）
3. iPhone 的 Safari 打开 `http://电脑局域网IP:8000`，例如 `http://192.168.1.5:8000`。
4. 点 Safari 底部「分享」→「添加到主屏幕」，即以全屏 App 方式使用，之后可离线打开。

### 方式二：部署到 GitHub Pages / Vercel（公网可随时访问）
1. 上传整个文件夹到仓库 / 项目。
2. GitHub Pages 设为仓库根目录；Vercel 直接导入该仓库即可。
3. iPhone Safari 打开生成的 https 地址，再「添加到主屏幕」。

> 手机与电脑必须在同一局域网时，方式一才能访问。

## 目录结构
```
folia-ios-pwa/
├─ index.html          主程序（播放器 + 歌词）
├─ manifest.json       PWA 清单（主屏幕安装）
├─ sw.js               离线缓存
├─ icons/              应用图标（192/512/apple-touch-icon）
└─ make_icons.py       图标生成脚本（可复跑）
```

## 说明与边界
- 数据完全存在本机浏览器 IndexedDB；换浏览器 / 清除网站数据会清空曲库，请勿清理该站点缓存。
- 音频文件不上传任何服务器，仅本地播放。
- 播放需用户点击触发（iOS 不允许自动播放）。
- 已由 `shot.py` 自检：桌面与手机视口布局、初始界面、脚本运行均正常；真实「添加音乐 + 歌词同步」建议你在浏览器里实际操作确认一次。
